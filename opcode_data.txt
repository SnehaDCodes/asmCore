1. Introduction
This specification outlines the essential IA-32 machine-code encodings tailored for a two-pass assembler implementation, focusing exclusively on 32-bit registers and operand types. It details the structure of variable-length instructions and their constituent encoding fields, specifically:

a. Opcode: Primary instruction identifier byte(s).
b. ModR/M & SIB Bytes: Addressing mode, register specifiers, and scaled-index-base modifiers.
c. Displacements & Immediates: Explicit 32-bit address offsets and immediate data constants.

2. IA-32 Instruction Byte Diagram

3. Encoding Field Meaning

Field  | Meaning                                                                            
-------+------------------------------------------------------------------------------------
ModR/M | Contains MOD, REG and R/M fields and identifies 32-bit register or memory operands.
SIB    | Scale-Index-Base byte used for complex 32-bit memory addressing.                   
+rd    | Used by B8+rd and similar 32-bit register opcode families.                         
id     | 32-bit immediate.                                                                  
cd     | 32-bit relative displacement.                                                      
disp32 | 32-bit memory displacement.                                                        


4. 32-bit Register Encoding Table

Register | Code
---------+-----
EAX      | 000 
ECX      | 001 
EDX      | 010 
EBX      | 011 
ESP      | 100 
EBP      | 101 
ESI      | 110 
EDI      | 111
